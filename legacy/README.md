# Legacy SigmaShip prototype

These files preserve the original vanilla HTML/CSS/JavaScript prototype as a
design and workflow reference during the Nuxt migration.

They are **not** production application source and are not loaded by Nuxt.

The original prototype intentionally remains available here so product details
can be migrated without carrying its compressed renderer architecture into the
new application.

Do not add new features to these files. New work belongs in the modular Nuxt
application under `app/`, `server/`, `shared/` and `supabase/`.
