# SigmaShip

Shipping, optimized.

Initial interactive product prototype for a Canadian multi-carrier parcel shipping platform.

## Included
- Marketing homepage and instant quote entry
- Rate comparison flow
- Shipment checkout demo
- Customer dashboard and shipment history
- Tracking
- Address/package/integration/settings application shells
- Billing and saved payment-method UX
- Responsive layout

## Payment security
SigmaShip must not store raw PAN/card numbers or CVVs. Production payment methods should be vaulted/tokenized by a PCI-compliant payment service provider. SigmaShip should retain only the provider customer/payment-method IDs and safe display metadata.

## Status
Front-end prototype only. Carrier rates and shipments are illustrative. No live carrier, authentication, database, or payment processing is connected yet.
